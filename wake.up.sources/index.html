MAG — WakeUp Sources Test

About this test

This page reads the current wake-up sources with gSTB.GetWakeUpSources() and applies the selected values with gSTB.SetWakeUpSources().

It can also be opened in a regular browser to test the UI and keyboard navigation. STB API calls will report their availability in the status block.

Navigation

↑ / ↓ — move between controls
Enter — activate / enter source list
Back / Esc — leave source list
0–6 — toggle source by ID globally
